# `@full-content-inventory/shared`

Shared types, utilities, and constants used across all packages in the Full Content Inventory monorepo.

---

## What it does

This package is the **foundation** of the monorepo. It contains:

- **TypeScript types** — `InventoryRow`, `CrawlConfig`, `CrawlResult`, `SummarizeConfig`, etc.
- **CSV I/O** — `readInventory()` and `writeInventory()` with consistent column ordering.
- **Path utilities** — `urlToFilename()`, `sanitizePath()`, `ensureDir()`, `ensureDirForFile()`.
- **MIME detection** — `isBinaryAsset()`, `EXT_TO_MIME` mapping.
- **Column constants** — `INVENTORY_COLUMNS` defines the canonical CSV header order.

Every other package (`crawler`, `gws-sync`, `ai-summarizer`, `cli`) depends on this package for type safety and shared logic.

---

## Installation

This package is a workspace dependency. It is automatically available to all sibling packages via:
```json
"@full-content-inventory/shared": "workspace:*"
```

From the monorepo root:
```bash
cd src && pnpm install
pnpm -r run build
```

## `urlToFilename()` — critical shared contract

This function is the **single source of truth** for converting a URL to a local `.txt` filename. Both the **crawler** (writer) and **gws-sync / ai-summarizer** (readers) must produce identical output.

### Behavior

| URL | Output |
|-----|--------|
| `https://example.com/` | `homepage.txt` |
| `https://example.com/index.html` | `homepage.txt` |
| `https://example.com/about` | `about.txt` |
| `https://example.com/café/page.html` | `cafe/page.txt` (unidecode transliteration) |
| `https://example.com/services/consulting/` | `services/consulting.txt` |

### Security features
- **Percent-decoding** with bounded iterations (max 3 passes) to catch double-encoded `%252e%252e`.
- **Filters `.` and `..` segments** to prevent path traversal.
- **Strips HTML/PHP/ASP extensions** before sanitization.
- **Replaces invalid characters** with hyphens.

## `INVENTORY_COLUMNS` — canonical CSV schema

The inventory CSV has exactly these columns, in this order:

```
URL, URL_finale, Titre, Description, Resume_200_chars, Type_de_page,
Profondeur_URL, Nb_mots, Statut_HTTP, Langue, Date_modifiee, Canonical,
Noindex, Nb_images, Fichiers_liés, Lien_Google_Doc, Lien_dossier_Drive,
crawl_status, sync_status, ai_status, error_message
```

**21 columns total.** If you encounter `Invalid Record Length: columns length is 21, got N`, the CSV was generated by an older version. Re-run the crawler to regenerate with the current schema.

## The Happy Path

This package has no standalone CLI. It is consumed by sibling packages:

1. **Crawler** calls `writeInventory()` and `upsertRow()` to persist crawl results.
2. **gws-sync** calls `readInventory()` and `writeInventory()` to sync to Drive.
3. **ai-summarizer** calls `readInventory()`, `writeInventory()`, and `urlToFilename()` to classify and summarize.
4. **All packages** import shared types for compile-time safety.

## Troubleshooting

### `Invalid Record Length` when reading inventory
**Cause:** The CSV header doesn't match `INVENTORY_COLUMNS`.  
**Fix:** Regenerate the inventory with the crawler, or manually add missing columns.

### `urlToFilename()` produces different paths on crawler vs. reader
**Cause:** Version mismatch between packages.  
**Fix:** Rebuild the entire monorepo (`pnpm -r run build`) to ensure all packages use the same `shared` version.

### Type errors after adding a new column
**Cause:** `InventoryRow` interface was updated but a consumer hasn't been rebuilt.  
**Fix:** Run `pnpm -r run build` to propagate type changes.
